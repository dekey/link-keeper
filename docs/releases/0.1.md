First release of Link Keeper: an Obsidian plugin that adds a link to a note only if the note
does not have it yet. If the link is already there, it tells you and changes nothing.

## What it does

- **Three commands** (command palette, Ctrl/Cmd+P), each can get a hotkey:
  - *Add link to target note*: asks for a link and adds it to your link note (default `Links.md`).
  - *Add link to current note*: the same for the note you have open.
  - *Add selected link to target note*: adds the text you selected in the editor.
- **Link icon** in the left ribbon opens the same dialog.
- **Finds duplicates anywhere in the note**: in a list, inside a sentence, or inside
  `[title](url)`.
- **Web links are compared sensibly**: `http`/`https`, `www.`, capital letters in the domain
  and a trailing `/` do not make a link new. Path, query (`?x=1`), anchor (`#part`) and port
  (`:8080`) must match.
- **Note links** like `[[My Note]]` are compared without capital letters.
- **Each new link goes on its own line at the end of the note.** Nothing else moves.
- **Clear messages**: ✅ *Added to “Links”* or ⚠️ *Already in “Links”* (the note is not
  changed).

## Settings

- **Target note**: the note that collects links, e.g. `Inbox/Links.md`. Note and folder
  are created when needed.
- **Line format**: how each line is written, e.g. `- {link}` (default) or `- [ ] {link}` for
  tasks.
- **Pre-fill from clipboard**: starts the dialog with the web address you copied.

## Install

1. Download `link-keeper.zip` below.
2. Unzip it into `<your vault>/.obsidian/plugins/`. You get the folder `link-keeper/`.
3. In Obsidian, open **Settings → Community plugins** and switch **Link Keeper** on.

Works on desktop and mobile. No network access: nothing leaves your vault.

## Known limits

- A link in bold, italic or a table cell (`**https://…**`, `|https://…|`) may not be found
  as a duplicate.
- When you select a Markdown link `[Title](https://…)`, the whole text is checked, not only
  the web address.
- One link at a time: a selection with several links is added as one entry.
- *Add link to current note* saves the note directly, so the cursor position and folded
  sections in that note may reset.
- With a Japanese or Chinese input method, pressing Enter to confirm a word can submit the
  dialog too early.
