New command: **Sort links in current note**.

## What is new

- **Sort links in current note** (command palette, Ctrl/Cmd+P; can get a hotkey) sorts each
  block of link lines in the open note: 0–9, then a–z, by the last part of the link. All other
  lines stay where they are.
  - A link line holds one web link and nothing else. A list marker (`-`, `1.`) and a task box
    (`[ ]`) in front are fine.
  - A block is link lines right under each other. A blank line, text or a heading ends it.
  - Numbers, bullets and indents stay in place; a task box moves with its link.
  - The frontmatter and code blocks are not touched.
  - One Ctrl/Cmd+Z undoes the whole sort.
  - Pop-up: ✅ *Sorted n links in “Note”*, or *Links in “Note” are already in order*.

## Install or update

1. Download `main.js` and `manifest.json` below.
2. Put them in `<your vault>/.obsidian/plugins/link-keeper/` (replace the old files).
3. In Obsidian, switch Link Keeper off and on in **Settings → Community plugins**.

Your settings are kept.

## Known limits

- Note links (`[[Note]]`), Markdown links (`[title](url)`) and links with text around them
  are not sorted, and they end a block.
- A sub-item under a link does not move with it.
