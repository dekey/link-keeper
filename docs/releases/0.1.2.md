The sort command has a new name and now works in reading view too.

## What is new

- **Sort links in current note** is now **Link Keeper: Sort Current** in the command palette
  (Ctrl/Cmd+P). A hotkey you set for it still works.
- It shows whenever a Markdown note is open, in editing view and in reading view. Before, it was
  hidden in reading view.
- In reading view the sorted note is saved to the file, so Ctrl/Cmd+Z cannot undo it there. In
  editing view one Ctrl/Cmd+Z still undoes the whole sort. A note that is already in order is
  not changed.

## Install or update

1. Download `main.js` and `manifest.json` below.
2. Put them in `<your vault>/.obsidian/plugins/link-keeper/` (replace the old files).
3. In Obsidian, switch Link Keeper off and on in **Settings → Community plugins**.

Your settings are kept.
