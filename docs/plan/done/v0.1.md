## Out of scope for 0.1 (possible later)

- Several links in one go (paste a list, add each new one, report the duplicates).
- Searching for the link across the whole vault, not one note.
- Fetching the page title and writing `[Title](url)`.
- Adding under a specific heading instead of at the end.
- Ignoring tracking parameters such as `utm_source` when comparing.
