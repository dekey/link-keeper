## Decisions

- The end spaces stay in their place (the review's fix), which reverses the Task 2 deviation
  (they moved with the link). Both keep all text; this one also keeps line breaks in place.
- The per-list plan is not copied into the repo: it was dropped before any code, it points at
  `/tmp` prototypes that are scratch too, and `20261125-plan2.md` holds its design.
- `[ xX]` in `LINK_LINE_RE` kept: the pattern has the `i` flag, so dropping only `X` changes
  nothing (an equivalent change no test can catch). `[ xX]` reads clearer than `[ x]`.
- The no-break space test also checks the opening side (a no-break space, then three
  backticks), as both fence helpers changed.
- The frontmatter fence test uses a YAML block line that starts with two spaces and three
  backticks, not the review's `code:` line with three backticks at its end: a line that does
  not start with the fence never opens a code block, so it would not catch the mutant.
