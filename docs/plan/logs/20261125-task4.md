## Decisions

- [decision] No code change. Every requirement and every edge case in the task list is in the
  code and has a test that fails when the rule breaks (see "Checks run").
- [decision] Underlined headings (`Title` + `===` / `---` line) and Obsidian comment blocks
  (`%%` … `%%`) are not detected, so a link line can move out of or into them (checked in
  Deno: `Read https://x.com/zeta\n===\n- https://x.com/alpha\n` swaps the two lines). Not
  fixed: the plan defines a heading as a `#` line and a block as a ```` ``` ```` / `~~~`
  fence, and the task rules say not to add features the plan does not ask for. Added to the
  plan's "Known limits" for `SPEC.md`.
- [decision] A line that starts with ```` ``` ```` but is inline code (```` ```a``` text ````)
  opens a fence that never closes, so no link below it moves. This follows the plan's fence
  rule and fails safe (nothing moves wrongly). Added to "Known limits", not fixed.
