## Decisions

- [decision] `editor.transaction` instead of `setValue`. In the Obsidian app code
  (`/Applications/Obsidian.app/Contents/Resources/obsidian.asar`):
  - `setValue` dispatches one change `from: 0, to: doc.length`, so the whole note is
    replaced;
  - `transaction` builds all changes against the doc before the change, in one CodeMirror
    change set.

  So only changed lines are touched and it is one undo step. Folds staying in place was not
  checked in a vault (open item).
- [decision] Lines that start with an HTML comment never move (the reviewer's simpler fix),
  instead of working out block ends from the part of the line that stays.
- [decision] `release.sh` replaces files in place (`--clobber`) instead of delete + create.
  Without a notes file, a re-run keeps the old notes, which GitHub wrote when the release was
  created.
- [decision] The version check reads `manifest.json` with `sed` (no `jq`, no JavaScript).
  The repo's `manifest.json` says 1.0.0 while the only tag is `0.1`, so a `0.1` release now
  stops (known open item in `docs/plan/done/v0.1.md`).
- [deviation] `make zip` in CI: not done. The auto mode classifier blocked that edit in review
  fix 7, and it was not tried again.
- Not done: frontmatter that ends at `...` (from review 7, needs a check in Obsidian).
