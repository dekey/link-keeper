## What was asked

Task 2 of the plan: replace the whole-note sort with the block sort (read the note from top
to bottom, sort each block of link lines on its own). New `LINK_LINE_RE`, `linkLine`,
`skippedLines` and the block walk in `sortLinkLines`; remove `sortKey`, note links, Markdown
link titles, emphasis marks and all old block rules. Delete the tests of removed rules,
rewrite the frontmatter and fence tests, write new tests for rules 1–6 and the PR #2 review
case, move the acceptance fixture to the shared example, rewrite SPEC "Sorting links" short,
and break each rule once in a scratch copy.

## Decisions

- [deviation] Spaces and tabs after the link are part of `rest`, so they move with the link.
  The plan's `^(start)(rest)[ \t]*$` would drop them on write: text would be lost, and a sorted
  note with such spaces would always be rewritten ("Sorted n links" instead of "already in
  order"). New rule 4 test and a rule 1 table row; SPEC rule 4 says "the link and any spaces
  after it"; a note line in the plan.
- [decision] "A task box only after a list marker" is checked in `linkLine` (`box` without
  `marker` → `null`) with named groups, not with a lookbehind in the regex: easier to read.
- [decision] Marker-change test: the plan's lines, but the two list lines come in out of order
  (`[x] …/beta` above `[ ] …/alpha`), so the test shows they are sorted; it also checks the
  other direction (`- …/zeta` then `…/alpha` are two blocks).
- [decision] Rule 1 test: each table line goes over a line of the same shape whose key is `0`.
  A link line swaps with it (exact note, `links: 2`); any other line leaves the note as it is
  (`links: 0`). So a line wrongly taken in, or wrongly left out, fails.
- [decision] Kept the three "no link → not a link line" key tests and the "each line is read on
  its own" test: `LINK_LINE_RE` takes `URL_RE.flags`, so it still guards that `URL_RE` has no
  `g`.
- [decision] The acceptance count test now also has a one-line block, so the pop-up test checks
  rule 6 ("also blocks of one line").
- [decision] SPEC: the commands table row and the line above it are left for Task 5 (the plan
  puts them there); they are not wrong now.
- [decision] Break checks were done by hand, one scratch copy per rule edited with the Edit tool:
  a single script that broke all rules in a loop was blocked by the tool's safety check.
