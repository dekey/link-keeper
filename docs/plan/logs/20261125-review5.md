## Decisions

- [decision] Frontmatter follows Obsidian's `getFrontMatterInfo`, read in
  `/Applications/Obsidian.app/Contents/Resources/obsidian.asar`. The start is `/^---(\r?\n)/`
  and the end is `/---(\r?\n|$)/`, at a line start only; no end means no frontmatter.
- [decision] The undo merge was read in the same bundle. `transaction(t, e)` sets
  `userEvent = e`. The history joins a change into the one before it when
  `!userEvent || /^(input\.type|delete)/` matches, the time is within `newGroupDelay` and the
  changes are next to each other. So the origin `link-keeper.sort` keeps the sort apart.
  Typing right after the sort does not join it either, because `setCursor` adds a selection
  to that history entry.
- [decision] Emphasis marks are cut only for the sort key. The add command's duplicate check
  (`normalizeUrl` in `src/links.ts`) still sees `**url**` and `url` as different. That was
  there before this branch, and changing it changes the duplicate rules in SPEC.
- [decision] The 4-column underline limit counts from the first text line of the run (or the
  item's text column). A deeper indented line in the middle of a paragraph can still
  over-accept an underline: that only keeps a link in place.
- [deviation] `make zip` in CI: not done (blocked by the auto mode classifier in review fix 7,
  not tried again).
