## Decisions (owner)

- Design: per-list A+ (each list on its own; items move with their lines; blocks of link lines
  sorted). This reverses "All link lines, whole note" of the first plan.
- Goal: A+ plus the minor review fixes (`URL_RE` without `g`, `trimLinkEnd` one regex,
  `ssh -G --`).
- Scope:
  - sort core and tests;
  - docs (SPEC, README);
  - the minor fixes;
  - plan logs.

  The `Makefile`/`release.sh` zip mismatch is noted, not planned.
- Rules: the prototype rules as they are:
  - a blank line splits a list;
  - an item without a link keeps its position;
  - each number position keeps its number;
  - an item is sorted by its first line;
  - link blocks are sorted.
- Testing: Regular (code first, then tests).
