## Decisions

- [decision] Any spaces or tabs before an underline count. This can also mark a top-level
  line with a 4-space `---` under it as a heading. Then a link stays in place when Markdown
  would let it move. That is the safe side: nothing breaks, the link only stays.
- [decision] A list item is part of a heading when the underline indent is greater than the
  item indent. Markdown needs the underline to be at the item text's column; a 1-space
  underline also counts here (safe side, as above).
- [decision] Any spaces or tabs before a divider line count for the table end, the same as
  for the other block checks (`startsBlock`).
- [decision] Release: `&&` in the docs, plus a check in `release.sh`. The script does not
  build by itself. If the files were built on another branch and the tag was checked out
  later, the check does not see it. The docs say to build right before the upload, in one
  command.
