## Decisions

- [decision] A numbered line not starting at 1 is heading text even when the line above it is
  blank (where Markdown would start a list). That only keeps a link in place (safe side).
- [decision] A table starts at any non-blank line with a divider under it, also when the
  header has fewer cells than the divider (Markdown then sees no table). That only keeps the
  lines in place (safe side), and it also covers the fix 6 case.
- [decision] Lazy lines under a list item stay counted as heading text (review finding 8,
  lazy part): it only keeps a link in place, no structure can break.
- [decision] `release.sh` runs `make test zip` itself instead of taking file arguments, so a
  build from another commit can never be uploaded.
- [deviation] `make zip` in CI: **not done**. The Claude Code auto mode classifier blocked the
  edit of `.github/workflows/ci.yml` (it reads it as adding release work back, which the user
  had asked to remove). The CI comment and the SPEC/AGENTS lines that mentioned it were
  changed back.
- Not done (as suggested to the user):
  - `release.sh` deletes the old release before it creates the new one;
  - the tag vs `manifest.json` version check;
  - frontmatter that ends at `...` (needs a check in Obsidian);
  - `editor.setValue` and folds.
